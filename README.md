## 📊 Dataset Schema & Columns

Each entry is cleaned, normalized, and includes 14 structured attributes:

| Column | Type | Description | Example |
| :--- | :--- | :--- | :--- |
| `company_name` | String | Official registered name | OpenAI |
| `domain` | String | Clean root domain | openai.com |
| `website` | URL | Full HTTPS destination URL | https://openai.com |
| `category` | String | Primary market category | AI & Machine Learning |
| `description` | Text | Concise 1-2 sentence business description | Pioneer in artificial general intelligence... |
| `pricing_model` | String | Commercial pricing tier | Freemium, Usage-Based, Subscription |
| `funding_stage` | String | Current verified funding round | Seed, Series A, Series B, Public |
| `country` | String | Headquarters country | United States, France, Germany... |
| `headcount_estimate` | String | Team size bracket | 1-10, 11-50, 51-200, 500+ |
| `founded_year` | Integer | Year founded | 2015, 2022, 2023 |
| `tech_stack` | String | Core detected technologies & cloud stack | Python, PyTorch, Azure, React |
| `twitter_handle` | String | Official X/Twitter handle | @OpenAI |
| `linkedin_url` | String | Official LinkedIn company profile | linkedin.com/company/openai |
| `verified_date` | Date | Last verification timestamp | 2026-11-24 |
